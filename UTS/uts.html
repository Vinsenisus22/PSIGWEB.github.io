UJIAN TENGAH SEMESTER PRAKTIKUM SIG WEB


Esai Materi Praktikum SIG WEB

Tulisan ini berisi penjelasan mengenai materi perkuliahan praktikum SIG Web dari minggu ke-1 hingga minggu ke-7. Mata Kuliah Praktikum Sistem Informasi Geografi Berbasis Web membahas mengenai bagaimana data dan informasi geospasial ditampilkan melalui internet baik dengan platform desktop, mobile, maupun media lainnya. Materi mata kuliah ini dimulai dari pembahasan mengenai cara kerja internet dan halaman web, konsep dan cara kerja client server pada WebGIS, arsitektur WebGIS, serta desain dan evaluasi WebGIS. Praktikum SIG WEB merupakan salah satu mata kuliah pilihan jurusan Teknik Geodesi Universitas Gadjah Mada. Berikut beberapa materi yang telah dipelajari selama praktikum dari minggu ke-1 hingga minggu ke-7.


Pengantar SIG Web

Pengantar SIG Web materi ini berisi penjelasan mengenai capaian kompetinsi praktikum, materi-materi yang akan dipelajari. Internet menjadi syarat untuk menghubungkan semua perangkat elektronik di dunia, melalui website kita dapat membuka an menyimpan dan mendapati file HTML. Halaman web pada alamat yang sama dapat dipangil dari berbagai perangkat yang berbeda. Sebuah halaman web juga memiliki tampilan berbeda jika dibuka pada jenis perangkat berbeda.


Minggu ke-1 dan Minggu ke-2 - HTML, CSS, dan WIX

HTML adalah bahasa markup yang digunakan untuk membuat struktur dasar halaman web. HTML berfungsi sebagai dasar hampir semua halaman web di internet dan mencakup elemen dasar seperti teks, gambar, tautan, daftar, formulir, dan lainnya.

CSS adalah bahasa yang digunakan untuk mengatur tampilan dan gaya (style) elemen yang telah ditentukan dalam HTML. Dengan CSS, pengembang web dapat mengontrol warna, font, tata letak, ukuran, dan elemen desain lainnya pada halaman web dengan lebih mudah dan fleksibel tanpa harus mengubah semua elemen halaman.

Wix adalah sebuah platform pembuatan situs web yang memungkinkan orang membuat situs web mereka sendiri tanpa tahu banyak tentang pemrograman atau desain web. Untuk membuat halaman web, pengguna dapat mengunduh dan mengedit templete web yang sudah dibuat di Wix. Dalam praktikum materi ini, dibuat sebuah web dengan HTML dan CSS sederhana. Selain itu, dilakukan pembuatan Curiculum Vitae dengan menggunakan website WIX.


Minggu ke-3 - JavaScript

JavaScript adalah bahasa pemrograman yang digunakan untuk mengembangkan situs web interaktif dan dinamis. Javascript merupakan salah satu bahasa pemrograman yang paling umum digunakan di seluruh dunia untuk pengembangan web. JavaScript memiliki peran penting dalam menjadikan halaman web lebih responsif, berfungsi, dan interaktif.Pada praktikum yang telah dilakukan, dilakukan pembuatan script menggunakan java script untuk menjawab lima soal yang telah diberikan.


Minggu ke-4 - Bootstrap Framework

Bootstrap adalah sebuah framework front-end sumber terbuka yang digunakan untuk memudahkan pengembangan situs web dan aplikasi web responsif (responsive web) yang menarik dan berfungsi dengan baik. Framework ini dibuat oleh Twitter dan kemudian dikelola oleh komunitas open source yang luas. Bootstrap menyediakan serangkaian alat, gaya, dan komponen yang siap pakai untuk mempercepat proses pengembangan web. Pada praktikum yang telah dilakukan, Bootstrap digunakan dalam pembuatan CV yang berisi biodata pribadi pemilik web serta link tugas yang telah dikerjakan selama praktikum SIG WEB.


Minggu ke-5 dan Minggu ke-6 - Pebuatan WebGIS dengan Leaflet JS

Leaflet JS adalah sebuah perpustakaan JavaScript open-source yang digunakan untuk membuat peta interaktif di situs web. Leaflet dirancang untuk menjadi ringan, cepat, mudah digunakan, dan memiliki fokus pada responsif dan kustomisasi. Leaflet merupakan salah satu perpustakaan peta yang paling populer di antara pengembang web dan digunakan secara luas dalam proyek-proyek yang memerlukan integrasi peta interaktif. Pada praktikum, telah dilakukan pembuatan peta interaktif menggunakan Leaflet JS dengan menambahkan beberapa plugin seperti plugin geolocating dan print.


Minggu ke-7 - Leaflet JS dan GeoJSON

GeoJSON adalah sebuah feature yang dapat digunakan untuk menampilkan data spasial pada media web. LeafletJS dapat memanggil layer GeoJSON sebagai variabel dan ditambahkan pada peta. Pada praktikum ini dilakukan penambahan data dalam format shapefile ke dalam LeafleatJS, mengunakan shapefile daerah DIY.
